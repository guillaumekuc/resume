Chordex - Chord Relationships Catalog

Published by Open-source, Github
Jan 2026

Developed a standalone web-app, built with Vue.js and Pico.css, that lets musicians browse a catalog of all possible chord-to-chord transitions in the tertian harmonic space (192 possible moves given 4 chord qualities : major, minor, diminished & augmented) — a combinatorial, music theory-informed taxonomy tool. It also contains a chord progression generator that uses user-selected chord transitions as lego blocks to create fully original yet emotionally on target progressions. Features audio playback, keyboard visualisation, and affect-based tags.

Gridz - Perspective Plugin for Photoshop

Published by Gumroad
Jan 2021

Developed a Photoshop plugin that solves a common gap in perspective drawing: a static grid only matches objects sharing its orientation, so Gridz lets artists rotate the whole grid in 3D space instead. Built with JavaScript, HTML/CSS, and Photoshop Extension SDK. Implemented bottom-up trigonometric transformations for accurate perspective calculation and created an intuitive UI for manipulating 3D space parameters. Published commercially on Gumroad.
